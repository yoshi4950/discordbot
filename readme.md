# Discord Gemini AI多機能Bot

## 概要

このBolは **Discord** 上で動作し、Google Gemini（Gemini API）を活用した多機能AIチャットBotです。

## ✨ 主要機能

### 🤖 AI会話機能
- **参照モード**: Discord内部でファイル管理、アップロードしたファイル内容を会話に反映
- **英語学習モード**: 添削・会話スタイル切替・日本語フィードバック
- **常時返信モード**: チャンネル全発言に自動応答
- **会話履歴維持**: 直近100件の会話を文脈として利用

### 🛠️ その他のユーティリティ
- **自動メッセージ削除**: 指定時間ごとにチャンネルのメッセージを自動削除
- **ボイスコントロール**: 通話参加者のサーバーミュート／解除
- **スラッシュコマンド対応**: 全機能が予測変換で利用可能
- **機能別ヘルプ**: `/help`で機能ごとに整理された詳細ガイドを表示

> ⚠️ **注意**: ChatGPTやOpenAIは一切使用していません。

## 🤖 AI会話機能

### 基本会話
| 操作 | 方法 |
|---|---|
| AIに質問 | `@Bot名 質問内容` |
| ヘルプ表示 | `/help` |

### 管理者専用機能
| 機能 | コマンド |
|---|---|
| 常時AI返信 | `/ai_always always/disable/status` |
| 参照モード | `/reference mode on/off/status/reload` |
| 英語学習モード | `/english mode friendly/business/slang/off/status` |
| 自動メッセージ削除 | `/delete/delete-now/cancel-delete/delete-status` |
| ボイスコントロール | `/mute_all` `/unmute_all` |

> ⚠️ **注意**: 管理者機能はサーバー管理者権限が必要です。

- **全コマンドはDiscordのスラッシュコマンド補完（予測変換）に対応しています。**
- **`/help`コマンドで機能別に整理された詳細ガイドが表示されます。**

## 英語学習モード

### 概要
- ユーザーが英語で会話しながら英語力を向上できる「英語学習モード」
- 英語で返答＋日本語で添削・解説フィードバック
- 3つの会話スタイル（フレンドリー/ビジネス/スラング）を切替可能
- **直近100件の会話履歴を文脈として利用**

### 使い方
- `/english mode friendly` : フレンドリーな英会話＋優しい添削
- `/english mode business` : ビジネス英語＋厳密な添削
- `/english mode slang` : アメリカンスラング中心＋最低限の添削
- `/english mode off` : 英語学習モードOFF
- `/english mode status` : 現在のモード確認

### 例
```
/english mode friendly
```
その後、英語で話しかけると英語返答＋日本語フィードバックが返ります。

## 参照モード（Discord内部ファイル管理）

### 概要
- **Discord内部でファイル管理**: ユーザーがDiscordにファイルをアップロードして使用
- **DMにファイル保存**: アップロードしたファイルは各ユーザーのDMに安全に保存
- **指定ファイルの内容を会話の文脈に毎回含めて応答**
- **直近100件の会話履歴＋ファイル内容**をプロンプトに利用

### 使い方
- `/reference upload` : ファイルアップロード（2つの方法から選択）
  - **小さなファイル**: モーダルで入力（4000文字以下）
  - **大きなファイル**: メッセージ形式で制限なし
- `/reference list` : ファイル一覧表示＋ワンクリック参照設定
- `/reference mode on <ファイル名>` : 手動で参照モードON
- `/reference mode off` : 参照モードOFF
- `/reference mode status` : 状態確認
- `/reference delete <ファイル名>` : ファイル削除

### メッセージ形式操作
- `/upload:ファイル名.txt` : メッセージでファイルアップロード（制限なし）
- `/update:ファイル名.txt` : メッセージでファイル内容更新

### 特徴
- **PCに依存しない**: ローカルファイルではなくDiscord内で完結
- **個人ファイル管理**: 各ユーザーが自分専用のファイルを管理
- **セキュア**: ファイルはDMに保存され、他のユーザーからアクセス不可
- **分割送信対応**: 長いファイルも自動分割して保存・復元
- **制限なしアップロード**: メッセージ形式で大容量ファイル対応
- **ワンクリック設定**: ファイル一覧から直接参照モードに設定可能
- **ファイル更新機能**: 既存ファイルの内容を簡単に更新

## 🚀 セットアップ手順

### 1. 環境構築

```bash
# 依存パッケージのインストール
pip install -r requirements.txt
```

### 2. 環境変数設定

必要な環境変数：
- `DISCORD_BOT_TOKEN`: Discord Botのトークン
- `GEMINI_API_KEY`: Google Gemini APIキー

```bash
# .envファイルまたは環境変数で設定
DISCORD_BOT_TOKEN=your_discord_bot_token
GEMINI_API_KEY=your_gemini_api_key
```

### 3. Discord Bot設定

1. [Discord Developer Portal](https://discord.com/developers/applications)でアプリ作成
2. BotタブでBot作成、トークン取得
3. OAuth2 > URL Generatorで権限設定:
   - `applications.commands` (スラッシュコマンド)
   - `bot` (基本機能)
   - `Send Messages`, `Use Slash Commands`, `Embed Links`, `Read Message History`
4. 生成されたURLでBotをサーバーに招待

### 4. 起動と初期設定

```bash
# Bot起動
python main.py
```

## 🔒 セキュリティ・注意事項

### 🔑 APIキー管理
- **DM履歴保存**: APIキーやトークンはBotとのDM履歴にのみ保存
- **第三者アクセス不可**: パブリックチャンネルや他のユーザーからは閲覧不可
- **直書き禁止**: コードや設定ファイルにキーを直接記載しない

### 🏠 使用環境制限
- **プライベート環境推奨**: 信頼できるメンバーとのみ使用
- **公開サーバー非推奨**: 不特定多数がアクセスできる環境では使用しない
- **商用利用禁止**: 個人利用・学習用途のみ

### 📄 データ取り扱い
- **参照ファイル**: 機密情報を含めない（AI応答に含まれる可能性）
- **会話履歴**: ローカルに保存、外部送信なし
- **ファイルサイズ制限**: 参照ファイルは10MB以下

### 📜 利用規約遵守
- **Google Gemini API**: [Gemini API利用規約](https://ai.google.dev/terms)を遵守
- **Discord Bot**: [Discord Developer Terms](https://discord.com/developers/docs/legal)を遵守

## 🔧 トラブルシューティング

### 🚀 一般的な問題
| 問題 | 原因 | 解決方法 |
|---|---|---|
| Botが応答しない | 権限/トークン問題 | DiscordのBot権限、環境変数を再確認 |
| スラッシュコマンドが表示されない | 権限不足 | Bot招待時に`applications.commands`権限を追加 |
| Gemini AIが動作しない | APIキー未設定 | `GEMINI_API_KEY`環境変数を確認 |

### 📄 参照モードの問題
| 問題 | 原因 | 解決方法 |
|---|---|---|
| ファイルが見つからない | パス違い | 絶対パスで指定またはファイルの存在を確認 |
| ファイルが大きすぎる | 10MB超過 | ファイルサイズを削減または分割 |
| 文字化けエラー | エンコーディング問題 | UTF-8でファイルを保存 |

### 🕰️ パフォーマンスの最適化
- **会話履歴制限**: 100件で自動制限（必要に応じて調整可能）
- **ファイルサイズ**: 参照ファイルは小さいほど高速
- **APIレート制限**: Gemini APIの制限内で自動調整

### 📞 サポート
問題が解決しない場合：
1. `/help`で最新のガイドを確認
2. コンソールログでエラーメッセージを確認
3. 環境変数、権限、ファイルパスを再確認
